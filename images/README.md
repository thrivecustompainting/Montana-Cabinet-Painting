# Photos for the website

Add real photos here, then swap each `photo-placeholder` block in `index.html` for an `<img>` tag.

| File name | Where it shows | Size (min) |
|---|---|---|
| `hero.jpg` | Top of the page, right side | 1200 × 1500 (portrait) |
| `before-1.jpg` / `after-1.jpg` | Before/after slider (same angle!) | 1600 × 900 |
| `kitchen-1.jpg`, `vanity-1.jpg`, `hardware-1.jpg` | Gallery grid | 1200 × 900 |
| `og-image.jpg` | Preview when the link is shared on Facebook or in a text | 1200 × 630 |

Tips: daylight, lights on, no flash, phone held level. See BRAND.md section 7.
Save as JPG around 200–400 KB each so the page stays fast.
